# Educore LMS - Next.js Frontend

This is the Next.js frontend for the Educore Learning Management System, designed for deployment on Vercel and connected to a Strapi backend.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables in `.env.local`:
   ```env
   NEXT_PUBLIC_STRAPI_API_URL=http://localhost:1337
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
